## 1. ما وجدناه في الموقع الحالي

الموقع منشور على WordPress فوق قالب مستشفى/عيادة، وهذا هو مصدر أغلب المشاكل:

| المشكلة | الأثر |
|---|---|
| أنواع محتوى `doctor` و `doctor-category` و مسارات `/appointment` و `/cart` | روابط وصفحات لا علاقة لها بعمل الجمعية |
| ٦ مقالات إنجليزية تجريبية عن كوفيد وحصى الكلى والصحة النفسية | تظهر كأنها أخبار الجمعية في صفحتي الأخبار و«قالوا عنا» |
| تصنيفات المدونة: Neurology · Cardiology · Pathology · Pediatric · Laboratory | تصنيفات طبية على جمعية دعوية |
| صفحة «شركاؤنا» منشورة بعنوان فقط | صفحة فارغة في التنقل الرئيسي |
| صفحتا «التراخيص» و«السياسات واللوائح» = مشغّل PDF مضمّن (EmbedPress) بلا عناوين | لا يعرف الزائر ما الملف ولا تاريخه |
| صفحة مجلس الإدارة تحوي بطاقتي «Drone Service» و«Photography» بنص Lorem إنجليزي | يضر بمصداقية صفحة الحوكمة |
| نموذج طلب المنحة: صفحة واحدة بـ ١٥ حقلاً (WPForms) بلا حفظ ولا تتبّع | تسرّب مقدّمين، ومتابعة هاتفية للحالة |
| صفحة «منح الوافدين» — أهم صفحة — نص متصل طويل بلا بنية | أهم رسالة في الموقع أصعبها قراءة |
| رقم واحد حقيقي معلن: «٢ أعوام من الخبرة» | لا توجد أرقام أثر أخرى |

### المحتوى الحقيقي الذي بُني عليه التصميم

- **التعريف**: جمعية أهلية غير ربحية متخصصة في رعاية طلاب وطالبات المنح الدوليين الدارسين في الجامعات السعودية.
- **الأهداف الخمسة**: التقنية الحديثة في الدعوة · تصحيح المفاهيم المغلوطة · تعليم المسلمين أصول دينهم · الدعوة المتخصصة للفئات الاجتماعية · الاهتمام بالجاليات.
- **مجالات العمل الأربعة**: الدعوة العامة · الدعوة الإلكترونية · التدريب والتأهيل · الأبحاث والدراسات الدعوية (ببنودها).
- **محاور رعاية طلاب المنح**: الدعم الأكاديمي والتعليمي · الدعم النفسي والإرشادي · الإرشاد الديني والدعوي · التمكين والمشاركة المجتمعية.
- **مجلس الإدارة**: د. عبد الله بن دجين بن علي السهلي (رئيس) · د. فهد بن سعيد بن ناصر بن سعيد (نائب) · د. سالم بن عبد الله بن عامر العجمي (مشرف مالي) · د. عبد الرحمن عبد الكريم البراهيم اليزيد (عضو) · د. عثمان بن سليمان بن حمد العراجه (عضو). المدير التنفيذي: أ. شعلان عبدالله الشمراني.
- **محاور آراء المستفيدين**: تجربة تعليمية ممتازة · دعم شخصي · بيئة مرحبة · تنظيم الفعاليات (اقتراح تحسين) · موارد إضافية (اقتراح تحسين).
- **الاتصال**: ‎+966 53 464 6648‎ · info@safeer-sa.org · الرياض — حي السويدي، شارع سدير.
- **خبر حقيقي منشور**: توزيع ٥٠٠ كرتونة تمور مقدمة من جمعية سفير (٣٠ يوليو ٢٠٢٠).

## 2. نظام التصميم

### الألوان

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--primary` | `#0B4343` | العناوين، الشريط العلوي، الأزرار الأساسية |
| `--primary-dark` | `#063333` | التحويم، الأقسام الداكنة، التذييل |
| `--secondary` | `#1C8184` | الروابط، الأيقونات، التمييز |
| `--secondary-light` | `#DDF2F1` | خلفيات ناعمة، شارات، خلفيات الأيقونات |
| `--surface` | `#F6FAF9` | أقسام متبادلة |
| `--bg` | `#FFFFFF` | الخلفية الأساسية |
| `--text` | `#183333` | النص الأساسي |
| `--text-muted` | `#4F6B6B` | النص الثانوي — **معدّل** عن `#668080` |
| `--muted-decor` | `#668080` | أيقونات وزخارف فقط، لا نص |
| `--border` | `#DCE8E7` | الفواصل والحقول |
| `--alert` | `#B4532A` | الرفض والتحذير في اللوحة |
| `--success` | `#1E6B3C` | القبول في اللوحة |

**تعديل واحد على اللوحة الأصلية**: `#668080` على الأبيض يعطي تباين ٤٫٢٣:١ — أقل من حد WCAG AA (٤٫٥:١). استُخدم `#4F6B6B` (٥٫٧٦:١) للنص الثانوي، وبقي `#668080` للزخارف.

**الوضع الداكن** — ليس قلباً للألوان بل سُلّم ارتفاع من أربع درجات، كي تنفصل البطاقات عن الخلفية بدل أن تذوب فيها:

| الرمز | القيمة | الاستعمال |
|---|---|---|
| `--bg` | `#06191B` | خلفية الصفحة |
| `--surface` | `#0C2326` | الأقسام البديلة |
| `--card` | `#102A2D` | البطاقات، الشريط العلوي |
| `--raise` | `#16373A` | رؤوس الجداول، البلاطات، التحويم |
| `--border` | `#1F4649` | الحدود |
| `--sidebar` | `#041214` | شريط لوحة التحكم الجانبي (أغمق درجة) |
| `--app-bg` | `#0A1F21` | منطقة محتوى لوحة التحكم |
| `--band` | `#0A2E31` | الشرائط واللوحات ذات العلامة |
| `--primary` | `#3FB8B4` | الأزرار والعناصر الأساسية |
| `--on-primary` | `#052021` | الحبر فوق `--primary` (٧٫١:١) |
| `--secondary` | `#6ED3CE` | الروابط والتمييز (٨٫٥:١ على البطاقة) |
| `--text` | `#E9F4F3` | النص (١٥:١) |
| `--muted` | `#9DB7B6` | النص الثانوي (٧٫١:١ على البطاقة) |

الأخضر `#0B4343` لا يُستخدم خلفية في الوضع الداكن. ولأن `--primary` يصير فاتحاً هنا، فكل ما يُكتب فوقه ينقلب إلى حبر داكن `--on-primary` بدل الأبيض — وإلا هبطت النسبة إلى ٢٫٤:١. واللوحات ذات العلامة (تسجيل دخول البوابة، بطاقات الدعوة) تستعمل `--band` الداكن لا `--primary` الفاتح، حتى تبقى اللوحة لوحةً لا مساحة مضيئة.

### التخطيط

```

page padding   60px (desktop) · 20px (mobile)
section gap    88–104px
card radius    18–24px

button height  52–54px (الحد الأدنى للمس 44px)
```

### المكونات

- **الأزرار**: أساسي `#0B4343`/أبيض · ثانوي شفاف بحد `1.5px` · ناعم `#DDF2F1`/`#0B4343`. تحويم: `#063333` + `translateY(-1px)` خلال 200ms.
- **البطاقات**: خلفية بيضاء، حد `1px solid #DCE8E7`، استدارة 20px، بلا ظل ثقيل. تحويم: `translateY(-4px)` + الحد يتحول إلى `#1C8184`.
- **الأيقونات**: خطية، سماكة `1.75px`، أطراف مستديرة. لا أيقونات ثلاثية الأبعاد ولا رموز تعبيرية.
- **الشعار**: قوس معماري + كتاب مفتوح + ورقة صاعدة + نقطة. **الشعار في النموذج إعادة بناء SVG تقريبية — استبدله بملف الشعار الرسمي قبل التنفيذ.** ارتفاعه في الشريط ٤٢–٥٢px.

### اللغة البصرية

خطوط متدفقة مشتقة من ورقة الشعار، بشفافية ١٤–٢٥٪، خلف المحتوى، مرة واحدة في القسم. فاصل مقوّس بدل الخط المستقيم. لا تكرار للشعار كزخرفة.

### الحركة

| العنصر | التوقيت |
|---|---|
| دخول الشعار (أول تحميل فقط) | 0 → 1.2s: قوس → ورقة → نقطة → اسم |
| ظهور الأقسام عند التمرير | opacity 0→1 + translateY 30px→0، 500–700ms، تتابع 100ms |
| عدّاد الأرقام | 1.6s عند دخول القسم للشاشة |
| الانتقال بين الصفحات | opacity + translateY 8px، ~300ms |
| تحويم البطاقة | 250–350ms |

كل ما سبق يتوقف تحت `prefers-reduced-motion` ويظهر المحتوى فوراً.

### RTL والثنائية اللغوية

`<html lang="ar" dir="rtl">` افتراضاً. التصميم RTL أصلي لا انعكاس آلي لتخطيط إنجليزي: الشعار يمين، التنقل وسط، زر التسجيل يسار. كل حقل نصي له نسختان (ar/en)؛ الصفحة التي تنقصها الترجمة تعود للعربية بدل أن تظهر فارغة.

## 4. بوابة الطالب (٣ شاشات — جديدة)

1. **الدخول** — رمز لمرة واحدة (OTP) عبر الهاتف أو البريد، بلا كلمات مرور.
2. **حالة الطلب** — رقم الطلب، شارة الحالة، مسار من ٥ مراحل، تنبيه الإجراء المطلوب، ملخص البيانات، سجل التحديثات.
3. **مستنداتي** — رفع بالسحب، حالة لكل مستند (مقبول/مرفوض مع السبب/قيد المراجعة)، شريط اكتمال.

الحالات: `جديد → قيد المراجعة → مستندات ناقصة → مقابلة → مقبول | مرفوض`

## 6. ما يجب حسمه قبل التنفيذ

1. **ملف الشعار الرسمي بصيغة SVG** — الشعار الحالي في النموذج إعادة بناء تقريبية.
2. **أرقام الأثر الحقيقية** — عدد المستفيدين والبرامج والشركاء (موجودة الآن كـ `[—]`).
3. **صور حقيقية** — الصور في النموذج مواضع معنونة؛ التوجيه: صور إنسانية للطلاب والفعاليات، لا صور أرشيفية طبية.
4. **قائمة الشركاء وشعاراتهم**.
5. **مصير المحتوى القديم**: هل تُحذف المقالات الإنجليزية الستة أم تُؤرشف؟
6. **مسار الترحيل**: إعادة بناء على WordPress بقالب مخصص، أم Next.js + API منفصل؟ (الافتراض في ملف التنفيذ: Next.js + NestJS)
